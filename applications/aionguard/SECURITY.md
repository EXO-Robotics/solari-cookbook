# Security

AionGuard is an experimental hackathon project with a runnable local core. Live endpoint protection, production security, tenant isolation, and scalable operation have not been established. Review the [tested boundaries and limitations](docs/security-review.md) before using it.

Use only owned or explicitly authorized test environments and synthetic credentials. The demonstration does not authorize testing third-party systems or submitting real credentials to inspected pages.

If you find a vulnerability, use the repository's private vulnerability reporting option when available. Do not post credentials, personal data, or sensitive reproduction details in a public issue. If private reporting is unavailable, open a minimal issue requesting a private contact channel without disclosing the vulnerability.

Reports should identify the affected commit, the expected boundary, the observed behavior, and a minimal reproduction using synthetic data. Maintainers do not currently provide a response-time guarantee.
