# Commercial licensing

AionGuard's licensing framework permits **free personal and internal-business use** of future material explicitly covered by the [Personal and Internal Business Use License](LICENSES/AionGuard-Personal-Internal-1.0.txt). Resale, hosting for paying external customers, and commercial bundling of that material require a **separate written paid commercial agreement**.

Fees or revenue sharing are negotiated separately. No royalty rate, default debt, or percentage is imposed by the project license.

## What this covers

[LICENSING-COVERAGE.json](LICENSING-COVERAGE.json) identifies restricted additions by component and version/commit. It currently designates **no published implementation**. Previously released MIT code remains available under MIT, including commercial use and distribution. Existing MIT users do not owe fees under this update. Dependencies, upstream cookbook code and separately licensed assets retain their own terms.

| Use of explicitly covered future material | Permission |
| --- | --- |
| Inspect, run, or modify for personal use | Free |
| Run for an organization's own staff, devices, and internal operations | Free |
| Rent ordinary cloud infrastructure for that internal deployment | Free AionGuard use; provider charges still apply |
| Charge for installation/configuration/support of an internal deployment without selling or hosting the software | Free covered use |
| Share gratis, outside a commercial bundle, retaining licenses and notices | Permitted |
| Resell software copies, provide paid hosted inspections, or include it in a commercial product/subscription | Separate written paid agreement |
| Commercialize earlier MIT code without covered new material | Existing MIT permissions apply |
