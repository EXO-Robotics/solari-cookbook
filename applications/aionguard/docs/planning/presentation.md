## Message

AI investigates. Evidence decides.

Astra chooses which missing evidence is worth acquiring. The broker controls execution. AionGuard evaluates what the returned observations support. The protected click is the visible beginning of one investigation.

Make adaptive investigation visible; do not claim it is uniquely possible with a model. Explicit security rules remain deterministic. Investigation selection can respond to changing evidence. Whether Astra does that usefully is measured, not assumed.

## Present each investigation as a causal sequence

Use the existing investigation panel, evidence panel and timeline. Expand the first meaningful choice; keep subsequent repetitions compact. These are presentation states driven by server events, not timed successes.

| Step | What the audience sees | What it establishes |
|---|---|---|
| 1. Known and unknown | Two hypotheses; principal status and Jenkins runtime identity unknown; budget 4; final verification costs 1 | The actual decision context before Astra responds |
| 2. Available choices | Relevant catalog actions, canonical costs and possible evidence coverage | What Astra is allowed to choose; possible coverage is not a promised result |
| 3. Astra selects | Actual action name and one short model-provided decision summary, plus targeted uncertainty | Model-selected investigation, not model-assigned truth or private chain-of-thought |
| 4. Broker authorizes | Approved action, canonical cost, remaining credits, request reference | The request independently passed execution policy; rejected requests show their actual reason |
| 5. Collector returns | Separate observation cards with fact, source, observed time and revision | What was actually obtained; failure remains failure |
| 6. AionGuard evaluates | Assessment change and the specific observation/rule that supports it | The source of the verdict is visible |
| 7. Next uncertainty | Remaining gap and current budget, followed by the next actual request or stop | Investigation responds to its updated evidence state |

Do not expose page content in Astra's context to make this scene more interesting. Preserve the existing outgoing-request exclusion test.

## Judge answers

**Why use Astra if an algorithm can solve this fixture?**

“For these two fixed hypotheses, a deterministic policy can solve it. We include one that recognizes overlapping evidence coverage. We are testing Astra as an investigator whose choices respond to known facts, source validity and budget without prescribing a separate action sequence for each state. Our small evaluation shows how it performed here; it does not prove general superiority.”

**What exactly did Astra do?**

“It selected this permitted investigation from the evidence available at that moment. Here is the outgoing request projection, its selected action, the broker receipt, the returned observations and the independent assessment.” Use an actual captured trace.

**What if Astra chooses poorly?**

“It can waste budget, and we report that. It cannot create an observation or override the evaluator. If verification becomes unaffordable, the result remains unverified.” This is a designed boundary until demonstrated by the required tests.

**What if the page contains prompt injection?**

“Page content is excluded from the investigator's input. Our controlled test checks the serialized outgoing request for unique page markers and disallowed fields.” Claim the test passed only after executing it; this is not a universal prompt-injection certification.

**Did you prove exploitation or fix Jenkins?**

“No exploitation is demonstrated. We verified a changed prerequisite for this modeled exposure. Disabling CLI is not a software patch, and the baseline and fresh after-state remain separately recorded.”

**What is new?**

“Our demonstration connects a model-free protected-link block to a budgeted identity-exposure investigation and a separately verified defensive change. The contribution we can show is that complete workflow and its enforced evidence boundaries.” Do not claim the market is empty or that other products cannot do this.

## Closing

“Astra chooses what to inspect. AionGuard shows what the evidence supports. Even a defensive change needs a fresh observation before we report a verified after-state.”
