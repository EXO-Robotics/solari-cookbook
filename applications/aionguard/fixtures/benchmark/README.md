# Controlled detector corpus

`corpus.ts` declares scenario intent before running detection. It produces 150 inert pages from 30 templates, each with five correlated surface variants. The variants change only identifiers, headings, and reference numbers; they are **not 150 independent security scenarios**. Labels describe the authored scenario's intent, not a conclusion proved by its visible page content.

The groups contain 50 benign, 20 credential, 20 brand/domain mismatch, 20 redirect, 20 download, and 20 mixed cases. Ten mixed cases are explicitly ambiguous and excluded from binary confusion metrics. The benign set includes legitimate unlisted logins, external authentication, installers, and educational material that can trigger false positives. Malicious scenarios include text-only credential requests, brand impersonation without password fields, redirects, and extensionless or plain downloads that the current detector may miss.

Run `npx tsx scripts/benchmark-corpus.ts --live` from the repository root after configuring Solari credentials. This uses one billed sandbox with a fresh script-disabled browser context for each case. Static meta-refresh redirects and all page responses are fulfilled locally from uploaded data; all other browser requests are aborted. Contexts are also offline so missed interception fails closed. Navigation history is captured from actual main-frame navigation events. No payloads, form submissions, or authored scripts execute. Setup downloads Playwright and Chromium. This browser routing policy does not prove provider egress isolation or host protection.

The harness saves its generated manifest before running and writes `report.json` plus `cases.csv` under `runtime-data/detector-corpus-*`. Successful extraction is scored as FLAGGED if any heuristic triggers and UNDETERMINED otherwise. These are not navigation release decisions. Extraction failures remain error rows and are excluded from binary denominators, with their count reported separately; ambiguous cases are also excluded. Undefined ratios are null. Intent denominators, errors by intent, and conservative detection yield (true positives divided by all authored malicious cases, including failures) are also reported. An unavailable extraction artifact leaves attempted count unknown, never an assumed zero.

Per-case extraction timestamps use the shared sandbox and browser and must not be presented as fresh-sandbox latency or click-to-decision measurements. Astra is not invoked. Results only describe this authored corpus, not general phishing recall, independent holdout performance, or real-world accuracy. Source, worker, detector, harness, generated manifest, and individual HTML hashes identify the exact material used.
